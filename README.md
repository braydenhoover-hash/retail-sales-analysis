# retail-sales-analysis
This project was one of my first end-to-end data analytics projects and gave me the opportunity to work through the complete analytics process—from cleaning raw data to building an interactive dashboard.

I started with a retail sales dataset containing over 10,000 transactions and used Excel to clean the data, MySQL to explore and analyze it with SQL, and Power BI to create a dashboard that highlights important business trends. The goal of the project wasn't just to create charts, but to answer real business questions and present the results in a way that's easy to understand.

Project Goals
Clean and prepare raw retail sales data
Analyze business performance using SQL
Build an interactive Power BI dashboard
Practice turning raw data into business insights
Strengthen my skills with Excel, SQL, and Power BI

Data Preparation

Before beginning the analysis, I cleaned the dataset in Excel by:

Removing duplicate records
Formatting columns for consistency
Checking for missing values
Creating a Profit Margin column
Exporting the cleaned dataset for SQL analysis

This step helped ensure the data was accurate before moving into analysis and visualization.

SQL Analysis

Using MySQL, I wrote queries to answer several business questions, including:

What are the company's total sales and total profit?
Which regions generate the most revenue?
Which product categories are the most profitable?
Which customer segment contributes the most sales?
Which products generate the highest revenue?
How do sales change over time?

These queries formed the foundation for the Power BI dashboard.

Key Insights

A few interesting findings from this project:

The West region generated the highest total sales.
Consumer customers represented the largest share of overall revenue.
A relatively small number of products accounted for a significant portion of total sales.
Sales patterns changed throughout the year, highlighting seasonal trends.
Discounting appeared to influence profitability and is an important metric to monitor.
What I Learned

This project helped me become much more comfortable working with SQL and Power BI. More importantly, it taught me that data analysis is more than writing queries—it's about organizing information, identifying trends, and presenting insights that can support better business decisions.

It also gave me experience connecting multiple tools together in a complete workflow instead of using them individually.
